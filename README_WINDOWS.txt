  ZTE K12 SMART TOWER ROTATOR & CONTROLLER (WINDOWS DISTRIBUTION)
========================================================================

ПАКЕТ ДЛЯ РОЗГОРТАННЯ ТА ЗАПУСКУ НА WINDOWS 10 / 11 / SERVER

ЩО ВСЕРЕДИНІ:
1. start-dashboard.bat  - Запуск веб-панелі на http://127.0.0.1:8080
2. rotate-now.bat       - Швидкий тригер ротації соти та оновлення IP в 1 клік
3. check-status.bat     - Перевірка сигналу, соти, оператора та IP
4. scan-towers.bat      - Повне сканування всіх частот (B3, B7, B8, B20)
5. zte-control.exe      - Автономний нативний виконуваний файл
6. tools/               - Python альтернатива (tools/cell_control.py)
7. web/                 - Веб-інтерфейс (web/index.html)

ШВИДКИЙ ЗАПУСК:
1. Підключіться до модема ZTE K12 через Wi-Fi (SSID: ZTE_1EE900) або по USB.
2. Двічі клікніть "start-dashboard.bat".
3. У браузері автоматично відкриється http://127.0.0.1:8080.
4. Для ротації після завершення завдань:
   - Натисніть кнопку "РОТУВАТИ" в браузері
   - АБО двічі клікніть "rotate-now.bat"
   - АБО з вашого скрипту/бота виконайте: curl http://127.0.0.1:8080/api/rotate
